# Bhavisha_Phase1

## grocery-run (Cubbie Skill)

Plans the cheapest, least painful grocery run for a student without a car: free shuttles first, then Valley Metro, then Uber, Lyft or Waymo, plus ride promo codes.

**Install on Cubbie:** text Cubbie this link:

https://github.com/brew-and-build/Bhavisha_Phase1/tree/main/skills/grocery-run

If it's already installed, text "update grocery-run".
